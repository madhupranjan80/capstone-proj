# cards-members

Custom **cards** block. Purpose: "Members Only" locked teasers (magazine landing page).

## Authoring (Document Authoring)

Two-column table, one row per card:

| cards-members | |
|---|---|
| image | Title (heading), subtitle, "Read More" label |

The "Read More" text is a plain label (the source content is sign-in gated, so it has no link).
Cards render faded with a yellow padlock badge in the top-left corner.

## Supported variations

No variations.
