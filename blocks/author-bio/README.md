# author-bio

Author byline card shown at the end of magazine articles.

## Authoring (Document Authoring)

One row with up to three cells:

| author-bio | | |
|---|---|---|
| avatar image | Author name (heading) + role | Facebook / Twitter / Instagram links |

The avatar renders as a 60px circle; the social links render as dark icon tiles
(the link text is used to pick the icon and kept as the accessible name).
Cells may be omitted.
